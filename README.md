# QCEBOX 下载

这里提供 QCEBOX 的引擎、Windows 环境组件、校验值以及对应开源组件的许可和源码材料。

[下载测试版引擎与环境](https://github.com/xiaoxiaoOCE/qcebox-downloads/releases/tag/windows-runtime-2026.10.12.1)

请优先在支持在线安装的 QCEBOX 主应用中点击下载引擎。应用会核对完整文件和签名，再进入 Android 安装确认；Windows 引擎安装完成后继续准备环境。无需手工逐个安装七个环境文件。

这套流程需要主应用 0.9.0-alpha136-online-install（145）或对应后续版本；旧主应用需要先升级一次。本次主应用仍为本地测试版本，未在此公开发布。

本仓库只存放分发材料，不提供游戏或用户数据，也不包含私有主应用源码。各组件保留各自的开源许可与来源说明。
